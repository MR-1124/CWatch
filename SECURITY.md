# Security Policy

## Supported Versions

Only the latest stable release receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take security and system integrity seriously. Because C:Watch operates with disk and filesystem analysis capabilities, protecting users against unintended file deletions and system safety is a core priority.

If you discover a security vulnerability or safety issue:

1. **Do not create a public GitHub issue**.
2. Open a private security advisory through the repository's **Security** tab, or contact the maintainer directly.
3. Include details:
   - Steps to reproduce the issue
   - Expected vs actual behavior
   - Windows OS version & environment details

We will investigate and release a patched version promptly.
